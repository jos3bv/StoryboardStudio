BV'Storyboarder 0.9.38
versionCode: 49
Base: BV'Storyboarder 0.9.37_REBUILT (based on the user's original 0.9.36 source)

Implemented the 8 additional requested adjustments:

1. Drawing is now rasterized incrementally into the active frame bitmap as stylus samples arrive. The live canvas displays the bitmap instead of rebuilding the complete current stroke path on every frame. Point data is retained in the project model for backward compatibility and to keep the existing lasso-selection implementation functional.
2. Undo/Redo history is no longer triggered by generic color/brush changes. It is recorded for completed drawing actions, clearing, text changes, imported image changes, lasso confirmation, and existing timeline/shot operations. Undo restoration preserves the current color, brush size, eraser state, opacity and pressure setting.
3. Render cache is bounded to two 1920x1080 bitmaps, released on Android memory-pressure notifications and Activity destruction. Decoded-image references and encoded-image cache are cleared when releasing cached data or replacing a project.
4. Saved session-copy filenames now contain only the session name and a trailing date in dd-MM-yyyy format. Session list labels show only that filename.
5. Reduced the main HSV picker height allocation from weight 4.0 to 2.8. Increased selected-color preview to full available inner width and 24dp high, matching the chroma bar height.
6. Added more flexible space before export buttons after reducing the picker block, so the bottom buttons have more breathing room.
7. Added 3dp top padding to timeline toolbar icon buttons for optical vertical centering.
8. Moved the slider rail 6dp left so its vertical track aligns with the right edge of the left panel.
