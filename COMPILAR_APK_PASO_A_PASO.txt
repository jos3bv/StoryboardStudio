STORYBOARD STUDIO — GENERAR EL APK SIN INSTALAR ANDROID STUDIO

ESTE PROYECTO USA GITHUB ACTIONS PARA COMPILAR EL APK EN LA NUBE.

1) Entra a https://github.com/ e inicia sesión.
2) Crea un repositorio nuevo llamado StoryboardStudio. Puede ser privado.
3) Dentro del repositorio, pulsa Add file > Upload files.
4) Descomprime StoryboardStudio_Android_Source_0.1.0.zip.
5) Abre la carpeta StoryboardStudio descomprimida y sube TODO su contenido a la raíz del repositorio. Debes incluir .github, app, build.gradle.kts, gradle.properties y settings.gradle.kts.
   IMPORTANTE: la carpeta .github puede estar oculta en Windows. Activa Ver > Mostrar > Elementos ocultos en el Explorador.
6) Pulsa Commit changes.
7) Abre la pestaña Actions.
8) Elige Build Storyboard Studio APK.
9) Pulsa Run workflow y confirma Run workflow, si no se inició automáticamente.
10) Espera el visto bueno verde. Entra en esa ejecución.
11) Abajo, en Artifacts, descarga StoryboardStudio-debug-apk.
12) Descomprime el ZIP descargado. El archivo app-debug.apk es el instalador.
13) Copia el APK a la Samsung Galaxy Tab S6 Lite, ábrelo desde Mis archivos e instala.

Si Android bloquea la instalación, permite temporalmente que Mis archivos instale aplicaciones de esa fuente. Instala únicamente el APK que generaste desde tu propio repositorio.

NOTA: el APK es de depuración para pruebas. Esta compilación todavía no está validada físicamente en la tablet.
