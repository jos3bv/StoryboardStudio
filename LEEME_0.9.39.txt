IMPORTANTE: El fallo de Checkout continúa porque el archivo SVG con nombre ilegible sigue registrado en el repositorio remoto. Un ZIP limpio no elimina por sí solo archivos antiguos cuando se extrae encima de una carpeta existente.

PASOS:
1. Extraer este ZIP directamente en la carpeta local raíz del repositorio StoryboardStudio, reemplazando archivos.
2. Ejecutar REPARAR_CHECKOUT_GITHUB.ps1 (clic derecho > Ejecutar con PowerShell) desde esa carpeta.
3. El script conserva y restaura todos los SVG válidos, retira la carpeta antigua del índice Git y vuelve a agregar la carpeta limpia.
4. Abrir GitHub Desktop. Verificar que aparezca la eliminación del archivo SVG con nombre ilegible.
5. Solo entonces hacer commit y push.

No ejecutar el workflow hasta que la eliminación del archivo problemático esté incluida en el commit.

Verificación: ZIP comprobado. No se ejecutó Gradle ni compilación Android.
