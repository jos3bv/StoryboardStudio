# BV'Storyboarder 0.9.31

Cambios respecto a 0.9.30:
- Sliders verticales de tamaño y opacidad acercados 2 dp al borde izquierdo del área de dibujo, que corresponde al borde derecho del panel lateral; el contenedor permanece sin margen horizontal.
- Botones del panel izquierdo (herramientas, importar y exportar) con márgenes de -1 dp en sus cuatro lados para eliminar las separaciones visibles y juntar sus bordes.
- Barra de timeline: padding superior uniforme de 5 dp para los botones de los tres grupos.
- Botón Play aumentado a 32 dp para compensar el menor peso visual del triángulo y alinearlo con el resto de iconos.

Versión Android: versionCode 42, versionName 0.9.31.
